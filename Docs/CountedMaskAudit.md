# Counted UI mask

OriginalCountedMask restores UIMgr.SetMask (0x9F8694) and delayed release 0x9F89D8. Each true call increments the counter before activating the mask, and schedules an independent release only for positive hideTime. False and delayed calls decrement, clamp nonpositive counts to zero and call SetActive(false). A remaining positive count produces no visibility update. Repeated true/extra false calls still invoke SetActive; pending callbacks are not cancelled or tied to acquisition IDs. Consequently an old timer may release a newer acquisition after manual release. The source ignores tip text, retained as an unused API parameter. Exceptions preserve prior mutations and stop later scheduling.
