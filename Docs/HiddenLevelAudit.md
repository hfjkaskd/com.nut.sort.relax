# Hidden level strip recovery

The current MainPanel HideLevel subtree is restored as Resources/Prefabs/Panels/HiddenLevel: 38 transforms and 143 source serialized objects. Original parent-relative coordinates, both HorizontalLayoutGroups, TMP fonts/materials, five Get-marker PunchRotation animations and the sub-round template are retained. Existing native OriginalRecordPunchRotation represents the same source parameters as the record guide. Source label_1 and label_160 participate in the original text-table localization pass. No static hierarchy is assembled in runtime code.

Init (0x9DCE90) hides only SubRoundGo. Refresh (0x9DCEA4) calls RefreshLevels, RefreshRound and RefreshSubRound in that order, even when RefreshLevels has hidden the entire owner. The current read-only reward projection now includes StartLevel and Stage2StartRealLevel from the third bear_list record, without rewriting the underlying server document.

RefreshLevels (0x9DCEC4) reads the third reward record before checking visibility. Level < 2, Level > Stage2RealLevel, or an incomplete pass-stage-two guide hides the owner. At/before RealLevel, all five number labels become 1 through 5; the first four Get objects are active when their number >= actual Level except index 2. Background states use displayed level: before/current/after map to sprite suffix 2/3/1. The current marker writes index * 0.25 to Progress. Actual Level >= StartLevel then forces fill to one.

After RealLevel, the first four labels become 5/10/15/20 and their Get objects are hidden. Completed/current/future intervals select suffix 2/3/1. Only a current interval writes fill: index * 0.25 plus the fractional interval * 0.25. The first three spans are five displayed levels, the fourth spans ten. The final node is left to RefreshRound. There is deliberately no generic fill reset or completed-all fill assignment; if no interval matches, the preceding fill remains.

RefreshRound (0x9DD754) initially hides both round parents when the level row is missing or TotalRound <= 0, but continues. Displayed level 4 writes Round/TotalRound to Round4, shows it only after round one, then hides Round5. Other levels hide Round4 and inspect third-record boundaries: <= StartLevel writes final label 5 and hides Round5; <= RealLevel writes 5 and the round ratio; <= Stage2StartRealLevel writes Stage2StartShowLevel and hides Round5; <= Stage2RealLevel writes Stage2StartShowLevel and the round ratio. After the final boundary it preserves the remaining state. Ratios show only when Round > 1. Missing table rows retain the original subsequent failure rather than creating a replacement row.

RefreshSubRound (0x9DDCCC) hides the sub-round group for absent/nonpositive SubTotalRound. Otherwise it clones the configured inactive template up to the original count, reuses existing entries, preserves first/last/interior line visibility behavior and sets white icons. Indices below SubRound use dian1; others use dian. Current index SubRound-1 fades alpha 1 to 0.5 over one scaled second with default OutQuad and infinite Yoyo. The current implementation samples the scaled clock so the blink resumes at its elapsed phase after owner reactivation. The original destruction path for decreasing positive counts does not remove list entries; this behavior is retained. The original 51-row forward progression uses four then five dots, so that path is not used by normal progression.

Validation covers both milestone branches, actual/displayed-level distinctions, guide hiding and continued refresh, inclusive boundaries, round-parent visibility, retained completed fill, source resource references, missing scripts, four-to-five template growth and reuse. The real Play host places the prefab under the existing MainPanel Top using isolated synthetic reward boundaries; it does not alter the saved wallet or player progression.
