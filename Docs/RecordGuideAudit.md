# Record guide panel recovery

The current typed export's TXRecordGuidePanel prefab is restored with its original static hierarchy, anchors, sizes, font assets/materials, sprites, two particle systems and standard Start Button. UGUI and TMP scripts reference the official Unity packages. Button listeners and feedback bind in code; no serialized UnityEvent calls were added. Large currency textures load by Resources path when the panel opens.

Behavior evidence: TXRecordGuidePanel.InitLssPanel 0x9D1EA0, RefreshLssPanel 0x9D2060 and StartCallback 0x9D2140. Base panel opening/closing uses the previously recovered configuration. Start's parent is zero scale for two seconds, then scales to one over 0.5 seconds with OutBack. Tip uses text ID 163 and label-prefixed text uses the original localization records. Close begins before the host completion callback and click sound; no new save point is introduced. The completed body/title/button tweens stop writing transforms.

The static HideLevel child has no Unity lifecycle methods; this panel does not call its Init/Refresh methods. Its inert script was removed while preserving the displayed hierarchy and serialized values. This is not a replacement for the separately required live HideLevel consumer on other panels.

The five Get-marker PunchRotation tracks are native AnimationCurves, with source one-second duration, vibrato 10, elasticity 1, Z amplitude 10, OutQuad on each segment and infinite Yoyo loops. DOTween.Punch 0xA0EB1C produces ten durations proportional to 1…10 and endpoints 10,-9,8,-7,6,-5,4,-3,2,0. Vector3ArrayPlugin 0xA29B38 applies easing within the selected segment. Hermite keys retain those quadratic segments without a runtime tween dependency.

GoldCode 0x9F7538 maps FR/DE to DE and US/CA/AU to US, leaving other values and casing unchanged. GetGoldTexture 0x9C43A4 loads Atlas/Golds/{code}1 for this panel. All nine corresponding source textures are included. This resource mapping does not implement country detection, AB routing, GM switching or reward grants.

The exported UI/PeriodicFlowLight shader was a dummy texture-only exporter body. The authored OriginalPeriodicFlowLight shader follows the current source GLES program: period=interval+duration, the band moves from -0.2 to 1.2 during duration, projected UV uses the configured angle, RGB gains the original triangular highlight and multiplicative quarter-strength term, and alpha remains the tinted texture alpha. Blend is SrcAlpha/OneMinusSrcAlpha, ZWrite/Cull are off and ZTest uses unity_GUIZTestMode. The source _FlowSpeed property is unused. Raw shader programs remain local and are not included here.

Validation: 24 full Unity regression groups pass. The real Play test instantiates the prefab in the current scene's UI canvas, verifies delayed appearance and US particle texture, captures the current render, dispatches a standard GraphicRaycaster/Button click, checks close-before-completion ordering, and verifies no added save. Latest local capture: Library/ValidationCaptures/record-guide.png. The capture was visually inspected for missing/magenta resources and broken layout.

**Production startup binding is still pending.** This is a completed panel component exercised in an isolated validation host, not a complete player onboarding chain. The post-record reward banner, newbie/assessment/reward consumers and lifecycle callback timing still need restoration before the initialization dispatcher is bound. Current source-device visual equivalence and Android/iOS parity are not proved by a target-only screenshot. SDK behavior is unchanged.
