# Complete MainPanel composition and lifecycle

MainPanelComplete.prefab assembles the entire current original MainPanel hierarchy: 105 objects and 434 serialized blocks. All 105 Transform/RectTransform blocks match the typed source exactly, including the four root children Top, Bottom, ExchangeMask, TargetRewardBanner and their ordering. The level-view helper formerly reused the original root component ID; its ID was remapped within this composed asset so MainPanel and Top retain distinct valid components. MainPanel.PlayerHint and Top.PlayerHint reference the same original object. No runtime static hierarchy creation is used.

OriginalMainPanelView restores MainPanel.InitLssPanel (0x9DE35C): base label initialization, Top.Init, Bottom.Init, TargetRewardBanner.Init, PlayerGoldGetHint.Init, exchange-mask listener installation and hiding. BaseLSSPanel.InitLssPanel (0x9C4A78) has no optional panel tween here because this exact prefab has no child named main. Its SetAllChildText (0x9B76C0) pass includes inactive TMP descendants, checks label_ before trimming, splits on underscore and uses the second token as ID. The ID conversion follows StringUtil.ToInt (0x9B466C): current-culture Int32.TryParse, original error diagnostic and zero on failure. Non-prefixed names retain their serialized text. In particular ExchangeMask/Tip is not a localized label_ node; its original text is retained.

RefreshLssPanel (0x9DE90C) refreshes Top then Bottom and does not reset hint deadlines, reward banner transforms or overlay visibility. MaskCallback (0x9DE890) requests SetExchangeState(false,0.5). The standard mask Button uses transition None, code listener replacement and the supplied common click gate/sound sequence. AddLSSListener is called with false for this button in the source: no press-scale feedback component is added. The cancel delay remains serialized in the prefab. The callback delegates actual exchange-state changes to the core manager; it does not hide the mask early on its own.

SDK treatment is unchanged; no fake response or editor-only production fallback was introduced.
