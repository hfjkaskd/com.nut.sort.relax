# CoinTip rotation playback

OriginalPunchRotation and FailureCoinTip.prefab restore the source four-object CoinTip subtree. All four RectTransform blocks match the source FailPanel after standalone root parent/order normalization. Original sprite, TMP font/material and texture references were retained/resolved; the current imported background texture was inspected. Source duration 2, vibrato 6, elasticity 1 and direction (0,0,10) are serialized in the prefab.

Evidence: DOPunchRotation getter 0xA2202C reads localEulerAngles; setter 0xA22048 converts Euler degrees to a local quaternion. SetPunch 0xA33E60 captures startup position, forces OutQuad and adds the start to each end value. Vector3ArrayPlugin 0xA29740 uses the original start for segment zero and the preceding endpoint thereafter. EvaluateAndApply 0xA29B38 selects a segment from accumulated durations and evaluates easing within it. Its Incremental displacement is final endpoint minus initial start; this closed punch therefore has zero per-cycle displacement. The native component implements this source configuration with the existing scene-global driver and no per-frame allocation.

58 regression PASS markers in Library/unity-punch-rotation-validation.log; no compiler errors or exceptions found, preference fixture restored with backup absent. Tests instantiate the actual CoinTip prefab and validate resolved visual dependencies, lazy local-angle capture, OutQuad samples in two separate segments, return to origin, twenty extra cycles with no drift, inactive/disabled global advancement and destroyed target cleanup. Edit-mode fixtures explicitly register with the global driver. Full rendered panel/device comparison is not covered by these state/motion tests.
