# TXPanel view restoration

Recovered the original 28-object TXPanel prefab, retaining all transforms, layout, UI images, TMP fonts/materials, progress fill configuration, original active states and serialized field references. A structural comparison verified all 79 non-script blocks from the 107-block source after excluding the three added component-list references (two standard Button feedback components and one pending-gold tween component). Original script placeholders are mapped to official Unity UI/TMP and recovered project components. Eleven missing sprite/texture dependencies are restored with source GUIDs. The GoldImage and ProgressTip punch components reuse their existing project implementations; the punch has its verified Yoyo configuration.

OriginalWithdrawalPanel binds the ordered refresh composition to real Image/TMP fields and instantiates actual PlayerInfo under the original PlayerInfoPos each refresh. Header, pending credit/display tween, default caption, live stage selection, progress and shared flag-reset/final-tip sequence all run through existing recovered logic. The StartLevel settlement provider reads the original target row then resolves the current level table. Click listeners bind in code to the standard Withdraw and Close Buttons; click gating precedes action and Click audio follows action. Direct guide GetCallback bypasses the button wrapper as in the source. Claim and close routing use the recovered branch flows.

Base animation inspection confirmed there is no direct main/Title child in this prefab (the visible title is main/Title1). Only main gets the opening scale curve and its completion invokes TXPanel.TweenEnd. Closing starts independent InBack tracks; Hide invokes the external hidden callback and schedules queue continuation after the serialized 2.5 seconds. No invented title tween or dynamic static layout is added.

Full Unity 2022.3.62f3 regression passed 123 markers in Library/withdrawal-panel-validation.log. New validation uses actual TMP/Image/Button fields, actual PlayerInfo and pending-gold tween, early guide/claim routing, click gating, close completion, delayed queue continuation, live post-credit login progress, repeated PlayerInfo instantiation and retained target-hint routing.
