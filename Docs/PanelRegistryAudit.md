OriginalPanelRegistry restores the ordering in UIMgr.ShowPanel (0x9E872C) and HideLssPanel (0x9F8294), using explicit integer IDs and name resolution instead of enum.ToString/reflection. Duplicate Show logs panel exist and returns null; new Show creates, registers, initializes, then refreshes. Hide invokes the view's hide adapter, rereads the registered panel, invokes destruction, then removes registration. Missing Hide logs panel not exist. Source exception ordering is retained: no rollback or cleanup is added after failed init/hide/destruction. Factory/adapters retain ownership of resource instantiation, parenting/activation, identity/argument assignment and concrete methods.
