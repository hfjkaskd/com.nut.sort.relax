# Failure lifecycle entry

OriginalFailureFlow restores Fail (0x9FC800): an already-set IsFail returns; otherwise IsFail is written before scheduling the panel callback. OriginalGameScene owns the failure state and exposes Fail/IsFail plus a Revoke wrapper that connects the live board's failure branch. Scheduling uses the existing scene-owned ScheduleDelay coroutine and WaitForSeconds, shared by Editor and device. OriginalSceneSession now serializes delay 3 and panel ID 10 (callback 0xA00218). The caller provides the panel request action; no substitute panel or automatic reward is created.

InitLevel (0x9E8174) clears IsInitDone and IsSucceed, not IsFail. RestartCallback (0x9D6BE4) clears IsFail before InitLevel, and ReviveCallback (0x9D6CDC) clears it before its SDK path. Consequently this implementation does not add an initialization reset, input gate, cancellation token or callback-time failure check. Explicitly clearing the flag allows another failure to queue while the old callback remains scheduled. Scheduling failure leaves the flag true. Showing the panel does not reset it.
